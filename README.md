# AI Testre Practice Lab

공개된 2025 AI TOP100 문제 **유형**을 참고한 비공식 로컬 연습 사이트입니다. 원본 프론트엔드, 문제 본문, 데이터셋, 정답 또는 채점 코드를 복제하지 않습니다. 모든 문제 데이터와 점수는 자체 설계입니다.

## 실행

Python 3.11 이상을 사용합니다.

```sh
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
PORT=7101 .venv/bin/python server.py
```

브라우저에서 `http://localhost:7101`을 엽니다. 개발 환경에 기록된 71000은 TCP 포트 범위를 초과하므로 7101을 기본값으로 사용합니다. 호스트 환경변수의 영향을 피하려면 `HOST`를 명시하세요.

- 연습 모드: 시간 제한 없음.
- 대회 모드: 서버가 3시간 제출 마감을 강제. 새 시도는 새 세션으로 생성.
- 문제 Markdown 복사와 데이터 ZIP 다운로드.
- 문항별 최고점 합계, 제출 피드백, 로컬 대회 랭킹.
- SQLite에 기록 저장. 쿠키로 시도 식별. `SIM_DB`로 DB 파일 경로 지정 가능.

로컬 신뢰 환경용입니다. 계정 인증과 공개 서비스 운영 기능은 포함하지 않습니다. 기본 바인딩은 `127.0.0.1`입니다. LAN 프리뷰는 `HOST=0.0.0.0`과 `ALLOWED_HOSTS=프리뷰호스트명`을 명시합니다. 허용 호스트는 localhost·127.0.0.1 및 쉼표로 구분한 ALLOWED_HOSTS이며 포트는 제외합니다. 이 저장소의 정답은 로컬 운영자가 코드에서 열람할 수 있으므로 보안 대회 운영 용도로 사용하지 않습니다.

## 합성 문제와 채점

| 유형 | 데이터 | 점수 기준 | 최대 |
| --- | --- | --- | ---: |
| 춘식도락 | 메뉴판 PNG 8장, JSON | 이름, 단백질 합, 식단 선택 정확 일치 | 50 |
| 고대 유적 | Python 코드 이미지 | 입력별 실행 결과 정확 일치 | 40 |
| 영상 팩트 체크 | 합성 자막 기록 | 시간 문자열, 횟수 정확 일치 | 30 |
| 전투 | 5종 능력치, 20개 전투 | attack × defense + bonus, 정답 행 비율 | 60 |
| PDF 추적 | 흰색 텍스트·가려진 레이어 PDF | 문장과 코드 정확 일치 | 40 |
| 입국 심사 | 축소 규칙 3개, 30명 | 가장 낮은 위반 번호, 정답 행 비율 | 80 |
| 몽타주 | 인물 묘사 Markdown | 아래 픽셀 유사도 기준 | 100 |
| 인수인계 | 워크스페이스·템플릿 Markdown | 구조 20, 이슈별 20, 제외 조건 10 | 70 |

합계 470점, 하위 문항 13개. JSON 행 순서는 무관하지만 모든 id가 중복 없이 포함되어야 합니다. 텍스트는 양끝 공백만 제거하고 대소문자와 내용을 비교합니다. 각 문항의 최고점을 유지합니다. 채점 기준 변경 전 SQLite 기록은 재채점하지 않으므로 새 기준으로 연습할 때는 새 SIM_DB 파일을 사용하세요.

몽타주는 1024×1024 PNG/JPEG, 10MB 이하, 세션별 분당 1회, 파일 SHA-256 중복 제출 금지를 적용합니다. 최근 4건의 평가가 화면에 표시됩니다. RGB를 64×64로 축소한 뒤 머리·눈·코·입 영역 각각의 RGB 절대 오차를 계산합니다. 영역별 기준선은 목표 영역의 평균색 단색 이미지 오차이며, `max(0, 1 - 제출 오차 / 기준선 오차) × 100`으로 정규화합니다. 네 영역 점수의 평균이 최종 점수입니다. **얼굴 의미 유사도 모델이 아니며 공식 점수식도 아닙니다.** 정해진 위치의 색상·윤곽 일치를 연습하는 기준입니다.

인수인계는 결정형 채점입니다. 1단계 제목은 템플릿 순서를 지키고 `##` 이하 제목은 허용합니다. 각 활성 이슈는 한 줄에 이름, 미해결 상태(`미해결`, `진행 중`, `개선 필요`, `복구 필요`), 담당자, 기한을 함께 씁니다. 날짜는 `7월 23일`, `07-23`, `2025-07-23` 형식(검색 인덱스는 24일)을 지원합니다. 같은 이슈를 해결 완료·폐기·제외로 적으면 해당 이슈 점수를 부여하지 않습니다. 제외 조건 10점은 활성 이슈가 하나 이상 맞을 때만 부여합니다. 자유로운 문장 의미를 판단하는 LLM 평가는 포함하지 않습니다. 영상 유형에는 실제 영상 대신 자막 기록을 제공합니다. 원본 난이도·개인화·배점·최종 순위 재현을 보장하지 않습니다.

X에서 확인한 비공개 본선 6개 유형(오목 10연승, 주차 등)은 이번 버전에 포함하지 않습니다. 전체 본선 9문제를 복원한 사이트가 아닙니다.

```sh
node --check static/app.js
```

테스트는 실제 HTTP 서버와 임시 DB에서 세션 분리, 최고점 유지, 시간 만료, 이미지 제한, JSON 부분점수, 파일 묶음 및 채점 결과를 검증합니다.

## 프리뷰 관리

```sh
mkdir -p tmp/pids
HOST=0.0.0.0 ALLOWED_HOSTS=preview.example PORT=7101 nohup .venv/bin/python server.py > /tmp/ai-testre-worktree1-server.log 2>&1 &
echo $! > tmp/pids/preview.pid
```

중지 시 `tmp/pids/preview.pid`의 PID를 확인하여 `kill`한 뒤 PID 파일을 삭제합니다. worktree 정리 전에 반드시 프리뷰를 중지합니다.
